# Инструкция по запуску проверки и синхронизации покупок

## Автоматический запуск при старте сервера

Чтобы автоматически запустить проверку при старте сервера, установите переменную окружения:

```
AUTO_VERIFY_ON_STARTUP=true
```

В Railway/Render:
1. Перейдите в настройки проекта
2. Добавьте переменную окружения `AUTO_VERIFY_ON_STARTUP` со значением `true`
3. Перезапустите сервис

После перезапуска проверка запустится автоматически через 30 секунд.

## Ручной запуск через браузер

После деплоя откройте в браузере:

```
https://your-app-url.com/api/verify-and-sync-recent
```

Или через curl:

```bash
curl https://your-app-url.com/api/verify-and-sync-recent
```

## Ручной запуск через API

POST или GET запрос:

```bash
curl -X POST https://your-app-url.com/api/verify-and-sync-recent
```

## Что делает проверка

1. ✅ Проверяет все покупки за **вчера и сегодня** из:
   - Stripe (основной аккаунт)
   - LowPrice (Stripe)
   - Primer (PayPal)

2. ✅ Сверяет с данными в Google Sheets

3. ✅ Автоматически синхронизирует недостающие покупки

4. ✅ Отправляет уведомления для новых покупок

## Результат

После выполнения вы получите отчет:
- Количество найденных покупок
- Количество недостающих покупок
- Количество синхронизированных покупок
- Ошибки (если есть)
